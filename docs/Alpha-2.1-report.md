## Сборка, проверка и подпись

Локальные задачи `:app:assembleDebug` и `:app:testDebugUnitTest` выполнены с JDK 17. При включённых `AUVYX_LIVE_SC=1` и `AUVYX_LIVE_LYRICS=1` выполнялись запросы к SoundCloud и LRCLIB. Сертификат локального APK и предыдущего облачного Alpha 2.0 имеет SHA-256 `f1466d42d35aaa3dc3e36da46cbbcc50797307f546fa83f43ce2c866938b4521`. Для установок из GitHub Actions с временным ключом совместимость зависит от сертификата установленного APK.

Все 25 локальных тестов прошли, включая живые проверки SoundCloud и LRCLIB. Дополнительно проверен выбор каждого из девяти акцентов через Compose UI.

[GitHub Actions для кода приложения d2edd92](https://github.com/AntiProkopka/Auvyx-music/actions/runs/45629690883) успешно собрал APK и выполнил сценарий на Android 15. Получены десять снимков экранов, импортирован локальный аудиофайл, проверены переключение интерфейсов, открытие плеера, очереди, исполнителя, альбома и панели EQ. Архив auvyx-glass-emulator содержит PNG и вывод gfxinfo/meminfo.

В сценарии с программным графическим драйвером SwiftShader из 283 кадров Android отметил 273 как janky (96,47 %), медиана 150 мс. Плавность остаётся открытой проблемой. Для оценки на POCO необходим замер на его GPU при прокрутке и воспроизведении.
