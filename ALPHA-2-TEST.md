# AUVYX Alpha 2.0 · Library Test

Тестовая сборка 16 на основе Provider Review 15. Основные источники в этой итерации — локальные документы Android и SoundCloud. Проверки выполнены на компьютере. Физический телефон и Bluetooth-гарнитура к среде сборки не подключены.

## Финальный прогон

12 тестов прошли на финальном варианте Library Test, пропусков и ошибок нет. CrossfadeTest — 2, LibraryRegressionTest — 7, SoundCloudLiveTest — 1, ThemeNavigationTest — 2. Использованы Robolectric API 33, SQLite, Compose UI, Media3 и живые запросы SoundCloud. Проверка кроссфейда измеряет команды громкости двух движков с управляемыми позициями. Проверка транспорта использует MediaSessionService и локальный WAV. Для обоих APK отдельно проверены подпись и идентификатор пакета.

## Установка и перенос

1. Если установлен **Provider Review**, открой **AUVYX-Alpha-2.0-Update-16.apk** и выбери **«Обновить»**. При желании заранее сохрани JSON через **Настройки → Данные → Экспорт медиатеки и настроек**. У этих двух APK одинаковые имя пакета и подпись.
2. **AUVYX-Alpha-2.0-Library-Test.apk** содержит последние доработки компактного экрана, учёта повторного прослушивания и команду остановки в меню плеера. Ползунок перемотки становится активным, когда Media3 подтвердит готовность трека и возможность перемотки. Это отдельная установка с новым сертификатом. Основная AUVYX и более ранняя Preview используют другие пакеты. На таком телефоне Library Test устанавливается рядом. Для переноса данных из версии с экспортом сохрани JSON там и выбери **Настройки → Данные → Объединить с резервной копией** в новой версии. Старую установку сохрани до проверки переноса. Если пропал доступ к документу, выбери **⋮ → Выбрать файл заново** или подключи исходную папку ещё раз.
3. Для GitHub распакуй ZIP в рабочую копию **AntiProkopka/Auvyx-music**, совместив корень архива с корнем репозитория. Удобно использовать отдельную ветку. В корне должны лежать settings.gradle.kts, gradlew, .github и app. При наложении на прежнюю копию удали старый app/src/main/java/com/nexus/music/ui/components/SoundCloudHistoryRow.kt — его типы заменены общей моделью истории. Сохрани локальный файл ключа подписи и параметры доступа отдельно от коммита.
4. На компьютере с JDK 17 и Android SDK 34 выполни следующую команду. Для Windows используй gradlew.bat. APK появится в app/build/outputs/apk/debug/app-debug.apk. Воспроизвести подпись тестового APK на другом компьютере можно только с тем же ключом.

```sh
./gradlew -Pauvyx.libraryTest :app:testDebugUnitTest :app:assembleDebug
```

Для дополнительного теста с живыми запросами SoundCloud перед сборкой установи переменную окружения AUVYX_LIVE_SC=1. Обычные тесты с SQLite и интерфейсом не зависят от доступности каталога. Для публикации проверенной версии используй обычный коммит и pull request с этой ветки. В рамках тестирования публикация на GitHub не выполнялась.
