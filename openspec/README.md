# OpenSpec в auvyx

Утверждённые ТЗ и внутренние отчёты хранятся в приватной копии проекта. В рабочей директории используйте каталог `.private/`.

Для работы с изменениями используйте `$openspec-propose` и `$openspec-apply-change`. Сверяйте критерии приёмки с утверждённым ТЗ и запускайте `openspec validate --all`.
