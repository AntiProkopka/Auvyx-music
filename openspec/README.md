# OpenSpec в AUVYX

## Источники требований

Исходные документы доступны авторизованным участникам в локальном каталоге .private. Для нового рабочего окружения восстановите этот каталог из приватной копии проекта.

- [Базовое ТЗ Alpha 2.1](../.private/docs/AUVYX-Alpha-2.1.md).
- [Этап 01 — EQ и тексты](../.private/requirements/alpha-2.1-stage-01.txt).
- [Этап 02 — графика и режимы качества](../.private/requirements/alpha-2.1-stage-02.txt).
- [План этапа 02](changes/alpha-2-1-stage-02/tasks.md). Задачи этапа открыты. Критерии этапа 03 фиксируются после утверждения отдельного ТЗ.

Исходные ТЗ сохранены дословно. При расхождении по предмету этапа применяется утверждённое уточнение этого этапа. Спорные требования уточняются у владельца проекта.

## Решения, проблемы и результаты

- Архитектура Glass UI, выборочное размытие и ограничения Android описаны в [отчёте Alpha 2.1](../.private/docs/Alpha-2.1-report.md).
- Этап 01, коммит `1ac718b`. EQ и тексты используют общую модальную оболочку. Текст прокручивается вместе с заголовком, ручная прокрутка приостанавливает автоматическое слежение. Остальной рендеринг сохранён как основа Low.
- Для `1ac718b` собран APK и прошло 27 локальных тестов, включая SoundCloud и LRCLIB. Проверены панели при 320 dp и шрифте 160%. Полный визуальный прогон на POCO, аудиовыход Bluetooth и проверка фоновых уведомлений остаются открытыми. [GitHub Actions](https://github.com/AntiProkopka/Auvyx-music/actions/runs/45755242982)
- Открытые проблемы Alpha 2.1 включают плавность Glass UI и комплект утверждённых фоновых материалов. Перечень и показания эмулятора есть в отчёте Alpha 2.1.

Для следующего изменения используйте `$openspec-propose`, для продолжения — `$openspec-apply-change`. Добавляйте решения в `design.md` соответствующего изменения, а результаты с ревизией и открытыми проверками — рядом с его `tasks.md`. Держите требования и статус проверок раздельно. Перед коммитом запускайте `openspec validate --all`.

## Инструменты Codex

| Инструмент | Версия или ревизия | Расположение |
|---|---|---|
| OpenSpec | 2.2.0 | CLI через npm, проектные навыки в `.agents/skills/openspec*` |
| Security Audit | `c1c8a8c1471069fb0e188eeaff69b8e8db6564a8` | Локально в `.agents/skills/security-audit` |
| Brag | `06379432a9243c951dfcc051153be18d2d261044` | Локально в `.agents/skills/brag` |

В CI и новых окружениях CLI можно восстановить командой `npm install -g --ignore-scripts @fission-ai/openspec@2.2.0` с Node.js 22.20+. Переменные `OPENSPEC_TELEMETRY=0` и `DO_NOT_TRACK=1` отключают телеметрию CLI.

Открывайте только инструкции навыка текущей задачи. Security Audit используйте для защитного статического анализа приложения, данных, токенов и сетевых запросов. Brag используйте для сценариев роликов и монтажа на локальных материалах. Для рендера Brag понадобится Hyperframes CLI, а для необязательного анализа музыки — NumPy и librosa. Исходники и секреты остаются в рабочем окружении. Два сторонних навыка установлены локально и исключены из Git.
