# Ведение требований AUVYX

## Purpose

Сохранить утверждённые требования и результаты проверки между сеансами Codex.

## Requirements

### Requirement: Связь с утверждённым ТЗ
Проект MUST ссылаться на исходное ТЗ и утверждённые дополнения при описании изменений и проверок.

#### Scenario: Возобновление работы
- **WHEN** начинается работа над изменением Alpha 2.1
- **THEN** открываются документы соответствующего этапа из указателя OpenSpec и проверяется состояние задач

### Requirement: Проверяемый статус
Проект MUST связывать закрытие задач с коммитом и результатами проверок.

#### Scenario: Проверка осталась открытой
- **WHEN** результат на устройстве не подтверждён
- **THEN** проверка остаётся открытой даже при успешной сборке и модульных тестах
