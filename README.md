# NEXUS Music — 0.3.0 «Фундамент»

Android-приложение (Kotlin + Jetpack Compose). Этот этап: локальная медиатека, плеер,
очередь, плейлисты, история, сохранение данных (Room + DataStore), фоновое воспроизведение (Media3).

## Как получить APK

1. Создайте на GitHub новый репозиторий (например `nexus-music`), ветка `main`.
2. Загрузите в него **содержимое** этой папки (не сам ZIP): Add file → Upload files.
   Убедитесь, что загрузилась папка `.github/workflows/build.yml`.
   Если её нет: Add file → Create new file, имя `.github/workflows/build.yml`, вставьте текст из этого проекта.
3. Откройте вкладку **Actions**. Сборка запустится сама после коммита
   (или Actions → Build APK → Run workflow).
4. Когда сборка станет зелёной, откройте её и скачайте артефакт **NexusMusic-debug-apk**
   (внутри ZIP с файлом `app-debug.apk`).
5. Установите APK на телефон (разрешите установку из неизвестных источников).

Если сборка красная: откройте шаг «Build debug APK», скопируйте последние ~60 строк лога и пришлите мне.

## Что работает в 0.3.0
- Добавление файлов и папок (системный выбор файлов, без лишних разрешений)
- Медиатека хранится в Room и не пропадает после перезапуска
- Плеер: play/pause, предыдущий/следующий, перемотка, перемешивание, повтор, очередь
- Фоновое воспроизведение, уведомление и управление с экрана блокировки
- Очередь и позиция восстанавливаются после перезапуска
- Плейлисты (создание, переименование, удаление, добавление/удаление треков)
- Избранное, история, поиск по медиатеке, сортировка
- Тема: системная / светлая / тёмная
