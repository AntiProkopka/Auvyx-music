# auvyx

auvyx — музыкальный плеер для Android. Текущая версия — **Alpha 2.1**.

- Воспроизведение локальных треков и поиск музыки в SoundCloud.
- Медиатека, избранное, история, плейлисты и очередь.
- Эквалайзер, Speed Lab и синхронизированные тексты песен.
- Два оформления: auvyx Glass UI и Material 3 Expressive.

Журнал изменений описывает обновления приложения. [CHANGELOG](CHANGELOG.md)
